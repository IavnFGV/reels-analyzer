# Derived Insights

`reels-analyzer` can enrich `reports/videos.csv` with lightweight derived fields
computed from existing report data. These fields are generated by
[src/reels_analyzer/insights.py](../src/reels_analyzer/insights.py)
and are meant to help compare stronger and weaker videos without requiring a full
ML ranking model.

## Purpose

The derived insights layer answers questions like:

- which videos outperformed the channel baseline for their posting period;
- what kind of hook a video appears to use;
- whether a hook is broad or specific;
- which quick tags can be used for slicing the dataset.

This layer is heuristic and explainable by design. It is not a claim that the
detected label is objectively correct. It is a controllable approximation that
should help generate hypotheses for manual review and notebook analysis.

## Source Fields

The analyzer reads only already available report columns:

- `upload_date`
- `view_count`
- `duration_sec`
- `scene_count`
- `words_per_second`
- `first_phrase`
- `title`
- `summary`
- `transcription_skipped_reason`

No extra API calls are made during this stage.

## Performance Logic

### `performance_cohort`

Derived from `upload_date` as `YYYY-MM`.

Examples:

- `2025-02`
- `2025-03`
- `unknown` if the date is missing or malformed

### `performance_baseline_view_count`

Monthly baseline for the channel.

Logic:

1. Group all rows by `performance_cohort`.
2. Collect positive `view_count` values for that cohort.
3. Use the median views of that cohort as the baseline.
4. If the cohort is unavailable, fall back to the global median across all rows.

Reasoning:

- Median is more stable than mean when some videos massively overperform.
- Monthly grouping reduces distortion from channel growth over time.

### `performance_score`

Calculated as:

```text
log1p(view_count) - log1p(performance_baseline_view_count)
```

Interpretation:

- positive: above baseline for the month
- near zero: around baseline
- negative: below baseline

This score is relative, not absolute. A lower-view month can still have strong
relative winners.

### `performance_bucket`

Based on `view_count / baseline`.

Rules:

- `breakout`: ratio >= 3.0
- `winner`: ratio >= 1.5
- `baseline`: ratio >= 0.67
- `underperformer`: ratio < 0.67
- `unknown`: views or baseline missing

These thresholds are intentionally simple and can be tuned later.

## Hook Logic

The hook analyzer uses a normalized text assembled from:

1. `first_phrase`
2. `title`
3. `summary`

in that order.

### `hook_subject`

Represents the rough topic or target of the opening hook.

Current heuristics:

- `money`: words like `деньг`, `финанс`, `доход`, `работ`, `бизнес`
- `energy`: words like `энерг`, `сил`, `ресурс`
- `rival`: words like `соперниц`, `любовниц`, `другая`, `конкурент`
- `relationship`: words like `отношен`, `любит`, `мужчин`, `он`, `она`, `бывш`, `партнер`
- `future`: phrases like `что будет`, `что произойдет`, `дальше`, `скоро`, `ближайш`
- `identity`: token `кто`
- `general`: fallback

### `hook_format`

Represents how the hook is framed.

Current heuristics:

- `timeline`: `в ближайшие`, `48 часов`, `сегодня`, `завтра`, `скоро`
- `reveal`: `тайно`, `скрывает`, `секрет`, `правда`
- `warning`: `опас`, `вредит`, `враг`, `осторож`, `нельзя`
- `promise`: `произойдет`, `ждет`, `случится`, `получите`, `будет`
- `question`: explicit `?` or words like `что`, `кто`, `как`, `почему`
- `instruction`: `сделай`, `нанесите`, `посмотрите`, `загадайте`
- `statement`: fallback

### `hook_emotion`

Represents the dominant emotional trigger inferred from the hook text.

Current heuristics:

- `jealousy`: `соперниц`, `любовниц`, `другая`
- `fear`: `вредит`, `враг`, `опас`, `утекает`, `теряете`
- `hope`: `любит`, `ждет`, `счаст`, `скоро`, `хорош`
- `validation`: `думает`, `в его глазах`, `кто вас любит`, `кто вас тайно`
- `curiosity`: generic `что` or `кто`
- `neutral`: fallback

### `hook_specificity`

Represents how concrete the hook seems to be.

Scoring logic:

- +2 for time-bounded wording such as `48 часов`, `сегодня`, `завтра`, `недел`, `месяц`, `скоро`
- +1 for a specific actor such as `он`, `она`, `мужчин`, `бывш`, `конкретного`
- +1 for explicit outcome framing such as `что будет`, `что произойдет`, `между вами`, `в его глазах`
- +1 for a concrete topic such as `деньги`, `энергия`, `отношения`

Mapping:

- `high`: score >= 4
- `medium`: score >= 2
- `low`: text exists but score < 2
- `unknown`: no source text

### `hook_strength_score`

Approximate 1-5 score for how forceful the hook looks.

Logic:

1. Start from specificity score.
2. Add bonus for strong amplifiers such as `внезапно`, `тайно`, `не ждете`, `очень скоро`.
3. Add bonus for explicit question form.
4. Clamp into `0..5`, but rows with text always get at least `1`.

This is not a prediction score. It is a simple heuristic for ranking hooks by
apparent intensity.

## Topic Logic

### `topic_cluster`

Higher-level grouping over hook fields.

Current rules:

- `relationship_tension`: `hook_subject == relationship` and emotion in `hope`, `validation`, `jealousy`
- `future_prediction`: `hook_subject == future`
- `money_signal`: `hook_subject == money`
- `energy_state`: `hook_subject == energy`
- `esoteric_tool`: text contains `руна`, `таро`, `карта`
- otherwise falls back to `hook_subject`

## Tags

### `insight_tags`

Compact report tags joined with ` | `.

Current tags may include:

- `subject:<value>`
- `format:<value>`
- `emotion:<value>`
- `specificity:<value>`
- `strong_hook`
- `long_duration` for `duration_sec >= 120`
- `short_duration` for `duration_sec <= 30`
- `dense_speech` for `words_per_second >= 2.5`
- `high_scene_count` for `scene_count >= 8`
- `no_transcript` if `transcription_skipped_reason` is present

## Practical Use

For channel analysis, start with these slices:

1. Compare `performance_bucket = breakout` vs `underperformer`.
2. Split inside one month using `performance_cohort`.
3. Group by:
   - `hook_subject`
   - `hook_format`
   - `hook_emotion`
   - `hook_specificity`
   - `topic_cluster`
4. Inspect `first_phrase` for the top combinations.

Suggested questions:

- Which `topic_cluster` over-indexes among `breakout` videos?
- Do `timeline` hooks outperform `question` hooks in the same month?
- Does `high` specificity beat `low` specificity for the same topic?
- Are longer, denser spoken videos outperforming short ones in the same cohort?

## Limits

- This is heuristic string matching, not semantic understanding.
- Results depend heavily on transcript quality and `first_phrase` quality.
- Some labels can overlap; the first matching rule wins.
- The current rules are tuned for Russian-speaking short-form content and are
  especially biased toward the tarot/relationship niche.
- Missing transcription can reduce quality, although `title` and `summary` still help.

## Maintenance

When changing rules in `insights.py`:

1. Update this document.
2. Run tests:

```bash
pytest -q
```

3. Recompute derived insights for an existing report:

```bash
reels-analyzer analyze-report --channel <channel>
```
